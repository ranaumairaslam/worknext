WorkNest API list
Base URL: http://localhost:5000
All requests return JSON.

Auth header (after login):
Authorization: Bearer <token>
Content-Type: application/json

Roles
- super_admin  -> Super Admin APIs
- company      -> Company APIs (login email from Create Company)
- team_leader  -> Team Leader APIs
- team_member  -> Team Member APIs
- client       -> Client APIs

Use a FRESH login token. Old tokens with role companyAdmin will 403 on company create APIs.


================================================================
PUBLIC
================================================================

GET /
{}
Expected: 200 { success: true, message: "Auth API is running" }

POST /api/dev/super-admin-token
{}
Expected: 200 token (local testing only)

POST /api/auth/login
{ "email": "act@example.com", "password": "your-password" }
Expected: 200 { success, token, user }

POST /api/login
Same body as /api/auth/login

POST /api/auth/forgot-password
{ "email": "act@example.com" }
Expected: 200 OTP sent / generated

POST /api/auth/reset-password
{
  "email": "act@example.com",
  "otp": "123456",
  "newPassword": "newpass123",
  "confirmPassword": "newpass123"
}

POST /api/auth/change-password
Header: Bearer token
{
  "currentPassword": "oldpass",
  "newPassword": "newpass123",
  "confirmPassword": "newpass123"
}

SUPER ADMIN  (role: super_admin)
================================================================

GET /api/super-admin/dashboard

GET /api/super-admin/companies
GET /api/super-admin/companies?status=active&payment_status=pending

POST /api/super-admin/companies
Body type: form-data
CompanyName=Code Craft
Industry=Software
AccountOwner=Ali Khan
CompanyLoginEmail=act@example.com
CompanyLoginPassword=pass123
CompanySize=11-50
Payment=5000
Location=Lahore, Pakistan
CompanyStatus=active
PaymentStatus=pending
PaymentReceipt=<image file>   (required if PaymentStatus=paid)

GET /api/super-admin/companies/:id
Example: GET /api/super-admin/companies/22

PUT /api/super-admin/companies/:id
{
  "companyName": "Code Craft",
  "status": "active",
  "industry": "Software",
  "address": "Lahore, Pakistan",
  "PaymentStatus": "paid"
}
status: active | inactive | pending | suspended
PaymentStatus: paid | pending | failed | cancelled

DELETE /api/super-admin/companies/:id

GET /api/super-admin/revenue
GET /api/super-admin/revenue/export
Expected: Excel file download

================================================================
EXPECTED RESPONSES
================================================================

200/201  success: true
400      validation failed (API is running, fix body)
401      missing/invalid token
403      wrong role or old token — login again
404      record not found (API is running)
405      wrong HTTP method
500      server error

Wrong URL returns:
{ "success": false, "message": "Route not found" }
